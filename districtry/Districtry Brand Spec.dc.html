districtry / brand spec

Districtry — district + directory. A national governance-boundary lookup: click any point, see every civic district that contains it and who represents you there. CivTech, explicitly: public data, honest gaps, no guessing. The fleet grows by state, starting with Illinois; metro instances live on subdomains under this one brand.

Spelling is Districtry, never Districtory. Type and spacing adopt the Industry design system; color and mark are Districtry's own. Tokens: tokens/districtry.tokens.css

The mark — 5c

A geometric lowercase d — ring plus ascender, never typeset — over three translucent irregular polygons. The polygons are district boundaries; their colors echo the map's layer encoding (brand violet, data blue, municipality magenta). Light surfaces use multiply blends; dark surfaces switch to screen blends with the tint set lifted one step. Small sizes (<24px) use the flat fallback: one violet polygon, knocked-out d.

  • Clearspace: half the d's ring diameter on all sides. Minimum canonical size 24px; below that, the flat fallback.
  • The d always sits on the polygon field in ink (#17161c) on light, paper (#ece9f4) on dark.
  • Never recolor the polygon set outside the three specified fills; never rotate the d.

Wordmark

  • One indivisible lowercase word — never Title Case, never hyphenated, never split across lines.
  • Set in Barlow Condensed 600, tracking +0.005em.
  • The optional instance tag — / illinois, / chicago — is Barlow Condensed 400 at 80% size, muted, one space around the slash.

Color — three tiers

Brand violet lives in chrome — buttons, links, pills, checked states — and never on the map. Blue belongs entirely to the data tier — selected boundaries, the point marker — so chrome and map data never visually collide. Chrome neutrals are warm paper and grays.
